# SENAMHI PIPELINE (IQUITOS PUNCHANA · EXTRACCIÓN)

import pandas as pd
from sklearn.ensemble import ExtraTreesRegressor

# 1. Quitar sesgo de meseta: no extrapola al alza
df['delta_tmax'] = df['tmax'].diff()  # Δy

# 2. Lags de memoria inercial (sin redes recurrentes)
for k in [1, 2, 3, 7, 14]:
    df[f'lag_{k}'] = df['delta_tmax'].shift(k)

# 3. Ajuste rápido sobre diferencias (CPU doméstica)
model = ExtraTreesRegressor(
    n_estimators=100, random_state=42)
model.fit(X_train, y_train_delta)

# 4. Inferencia recursiva y reconstrucción
pred_delta = model.predict(X_test)

1
La inercia vence a la complejidad: A 1–3 días, 14 días de memoria explican el 85% de la variación; sobra el supercómputo.
2
Restar salva a los árboles: Entrenar con niveles falla ante récords; con diferencias se proyectan olas de calor sin techo.
3
El cono protege las decisiones: Un rango P10–P90 calibrado protege presupuestos y cadenas de suministro ante friajes.
